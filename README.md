## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/AhmedFaisalCareer/Ahmed-Faisal-Developer.git
   ```

2. Open the project folder:

   ```bash
   cd Ahmed-Faisal-Developer
   ```

3. Open `index.html` in your browser.

No package installation or build process is required.

## 🌍 Deployment

This portfolio is hosted with **GitHub Pages**.

To publish updates:
1. Make your changes to `index.html`.
2. Commit and push the changes to GitHub.
3. Make sure GitHub Pages is enabled in the repository settings.

Your published website will update after GitHub Pages finishes deploying the changes.
